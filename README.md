# Global Health and Life Expectancy Data Visualization

This project is a comprehensive data visualization dashboard exploring global health metrics, life expectancy patterns, and related factors across different regions and income groups. Created for FIT3179 Data Visualization at Monash University.

## Project Overview

The dashboard consists of multiple interactive visualizations that explore:
- Global life expectancy patterns and geographical distribution
- Health expenditure and its relationship with life expectancy
- Disease burden analysis across different regions
- Regional comparisons and country-specific performance
- Impact of economic factors on health outcomes

## Visualizations

1. **Global Life Expectancy Map**
   - Choropleth map showing life expectancy distribution
   - Interactive year selection (2001-2019)
   - Color-coded regions with tooltips

2. **Health-Wealth Bubble Chart**
   - Relationship between health expenditure and life expectancy
   - Bubble size represents CO₂ emissions
   - Region-based color coding
   - Multiple filtering options

3. **Disease Burden Analysis**
   - Proportional symbol map for DALYs
   - Stacked bar charts for disease composition
   - Income group and regional breakdown

4. **Regional Performance Comparison**
   - Diverging bar chart for country comparisons
   - Regional averages and deviations
   - Income group filtering

## Technologies Used

- **Vega-Lite**: Data visualization grammar
- **HTML/CSS**: Dashboard layout and styling
- **Pure.css**: Grid system and responsive design
- **JavaScript**: Visualization embedding and interactions

## Data Sources

- World Bank Development Indicators
- Global Health Observatory data
- World Health Organization statistics

## Features

- Interactive filtering by year and region
- Responsive design for different screen sizes
- Consistent typography using Merriweather and Open Sans fonts
- Coordinated color scheme across visualizations
- Detailed tooltips and information panels

## Local Development

To run this project locally:
1. Clone the repository
2. Open the project in a web server (required for loading external data)
3. Access index.html in your browser
